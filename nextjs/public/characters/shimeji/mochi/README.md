# Sprites de Mochi (copia para el slice web)

Estos PNG son los dibujos de Katho, copiados desde
`chrome-extension/characters/shimeji/mochi/` **solo** para que Vercel / Next pueda
servirlos en `/companion` (`/characters/shimeji/mochi/walk-step-left.png`).

No es un look nuevo. El runtime de caminar / caer / trepar / sentarse en el
borde está portado de `runtime-core/mochi-shared.js` + `chrome-extension/content.js`.
